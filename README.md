# Atom Voice

**Live app:** https://atomvoice.vercel.app

Atom Voice is a real-time voice conversation app in the Atom suite — talk to it naturally and it talks back, live, with no turn-based delay. It streams your microphone audio over a WebSocket straight into the Gemini Live API and plays the spoken reply back as it's generated, all wrapped in an audio-reactive orb interface that pulses and shifts with the conversation.
